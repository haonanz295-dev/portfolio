# 音频来源 · v0.3

全部曲目为本项目原创程序编排与合成，不包含第三方歌曲、采样、《光遇》配乐或实地潜水录音。方向为柔和钢琴式泛音、缓慢和声、留白与海洋氛围，未声称具有治疗效果。

tools/arrange_music.py 生成六套旋律层与氛围层：22050 Hz / 16 bit / 立体声，A / B / A′、12 小节、乐句留白和立体声延迟，尾音环绕接续。

| 场景 | 标识 | 每层时长 |
|---|---|---:|
| 逐光浅湾 | shallow | 100.8 秒 |
| 珊瑚花园 | garden | 91.2 秒 |
| 水母之林 | jelly | 115.2 秒 |
| 回声峡谷 | canyon | 110.4 秒 |
| 鲸游星海 | whale | 134.4 秒 |
| 归潮日落 | sunset | 120 秒 |

音效 bubble / sonar / ray / whale / bell 沿用 tools/make_audio.py 的原创单声道合成。生物声音是艺术模拟，不是真实物种录音。呼吸、水流由 audio.js 实时滤波噪声合成，可独立静音。

再生成顺序：需要重做音效时先运行 make_audio.py，再运行 arrange_music.py。旧脚本同时写早期音乐，第二步才覆盖为新版编排。不需要 numpy。

音频与程序可随本项目修改复用，Three.js 另有 MIT 许可证。专业乐器录音、混音与空间声场留待后续；格式和解码检查不等同专业听感评审。
