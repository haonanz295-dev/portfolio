# Dialogue Abyss 对话深渊

一款面向成年玩家的单人海洋探索与NPC陪伴游戏案例。自由探索、动作、四种小游戏、可选表达、摄影与本机手记构成体验闭环。游戏不是诊疗或紧急支持服务。

## 运行

进入 `dialogue-abyss`，双击 `Launch.cmd`。需要Python 3.10或以上；也可进入 `dialogue-abyss/web` 执行 `python backend/server.py --port 4196`。

- 游戏：http://127.0.0.1:4196/
- 发布者后台：http://127.0.0.1:4196/admin

以上为本机地址，需保持服务运行，尚未部署公网后台。首次在后台创建自己的密码，没有默认密码。直接打开HTML可以体验本机游戏，但不能连接统计与后台。

WASD移动，空格上浮，C下潜，Shift加速，拖动鼠标环顾，滚轮调距离，E互动，Q动作，F声呐，Esc暂停。

## 目录

- `dialogue-abyss/web`：完整Web游戏与Python/SQLite后台源码。
- `dialogue-abyss/web/assets`：游戏运行用图像、概念、模型、图标和音乐。
- `dialogue-abyss/godot`：原生迁移基础，尚未完整覆盖Web功能。
- `docs/PRD-public.md`：公开版产品需求，已移除私人研究资料和出处。

## 状态与数据

当前为作品级Demo。移动端精修方案和生成式AI回应尚未完整接入，当前文本回应是作者脚本。后台内容与素材上传保存为草稿，不会自动生成可玩关卡。

默认不上传体验数据；玩家单独同意后才分享统计，反馈需另行同意。不要提交后台data目录、数据库、密码、令牌、真实用户记录或个人手记。公开部署仍需HTTPS、持久存储、备份、访问控制与上线验证。

本仓库不包含私人论文、文献全文、作品集、真实参与者记录或后台密码。概念资产是视觉目标，不等于精修实时模型。音乐为项目合成素材，不含光遇原曲。第三方引擎与库按附带许可使用；自有代码与美术未授予额外开源再分发许可。
