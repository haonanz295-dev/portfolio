本地OCR质检 · 正文背景三页规则 · 二分类版

本机PyCharm直接运行 document_qc_offline_ocr.py。
选择输入、输出文件夹。其余路径通常留空。保留旁边的tessdata目录。
运行时不联网，不使用Codex或千问，不消耗平台额度。
其他电脑先安装Python 3.10+及PyMuPDF：
python -m pip install "PyMuPDF>=1.24,<2"
Word/PPT转PDF需LibreOffice。

检查范围：默认每份文档最多前10页；不再单页空表提前拒绝。
输出只有“通过”“不通过”两个分类目录，另有报告及rule_notes.csv备注。

水印规则：
1. 封面、标题装饰页不计入正文重复页数。
2. 同一特征至少出现在3个不同正文页。
3. 必须有正文覆盖及背景绘制顺序的证据；原生文字可水平或斜向。
4. 矢量轮廓按形状和版面证据判断，不按固定品牌/文件名黑名单。
5. 仅1—2页、单页疑点、普通Logo/标题，不因此拒绝。
因此，两页文件即使有水印，也不会满足新的三页水印拒绝条件。
扁平扫描图的OCR可读字，但通常无法可靠恢复图内图层关系，不能保证检出。

空模板规则：
已检查全文，除封面/空白页外，全部内容页均为未填写模板，且没有实质正文，才拒绝。
正文/课件中夹带空表、同一页中有实质解释正文与空表，不直接拒绝整份。
颜色矩阵、图像信息图、装饰封面不因格子里没有文字被当成空表。
超过10页时只抽检，不能据此证明“通篇都是空模板”，因此不凭模板前缀直接拒绝。

二分类如何处理不确定性：
通过 = 所检查范围没有达到明确拒绝条件，不等于全文已确认合格。
OCR不足等非确定问题写入备注，按优先避免误拒的策略放行。
损坏、打不开、检查中断、复制失败等归“不通过”，报告注明technical_failure，区别于内容违规。

验证情况：
已验证三页背景水印、两页不足阈值、封面保护、前景叠加不满足底层条件、
局部空表、整份空模板、同页正文夹表、技术失败、二分类目录。
之前5份拒绝文件仅重测前10页，均未再因旧规则被拒绝；没有重跑全部232份。
这些验证不构成90%准确率保证，使用的是你明确放宽后的业务标准。
