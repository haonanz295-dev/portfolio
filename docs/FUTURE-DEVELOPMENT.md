# 对话深渊 · Demo 后续开发与预算

更新：2026-11-12。用于排期与询价，不是供应商报价；没有发生付费购买或生成。

## 本次交付边界

可玩主版本是 Web Demo。Godot 文件夹保留迁移基础，不代表与 Web 功能一致。七种海洋伙伴改为原创曲面模型，并细化潜水员装备；这是适用于 Demo 的风格化实时模型，仍有进一步雕刻、拓扑、UV 和骨骼蒙皮空间。模型工作室可旋转预览、保存图片、下载 glTF。

六章字幕序言、黑幕、限时加载、跳过/暂停、动态首页与设备语音试听已接入。精修渲染影片、正式角色配音没有制作，运行时明确标识为章节序言。五语言覆盖新设置、章节台词及部分旧界面，旧问卷、部分玩法、后台尚未完成本地化。可玩的中文流程是本次验收主体。

新增模拟心律、猜拳、海晶寻找和独处替代任务。数值属于潜水员的虚构状态，不读取硬件、摄像头或健康数据，不评价玩家心理状态。没有生命值、失败惩罚或因不社交而锁死内容；章节菜单可自由访问。当前稳定条件是累计15秒，不是连续保持；越界时缓慢回退。正常出口仍需三个地标和一次协作或独处准备。

## 预算建议（人民币，内部规划假设）

先保持 Demo 范围，优先完成中文与代表性一章，避免一开始为五语言、六短片和全资产同时付费。

### A · 继续自制

软件许可预算可为0元：Blender本身免费且可用于商业制作，但人力、学习和渲染耗时不为0。当前代码/模型继续复用。展示用静态托管可先使用已有平台额度；不承诺永久免费或无限流量。

### B · 工具辅助打磨

预留 **600–2,500元** 作为一轮模型生成、视频试制、配音和返工的工具成本上限建议。这个范围是项目预算安排，不是任何服务的现行套餐报价，不保证可覆盖全部精修要求。

- 模型：先试潜水员、鳐鱼各一件，确认可编辑性与轮廓后再扩展七动物。生成出来仍需清理、绑定和导入测试。
- 视频：先完成浅湾12秒样片，再复制制作流程到其他五章；每条预留3–5次试制。按“实际单次价格 × 尝试次数”核算，不能只按成片秒数计费。
- 配音：先中文两声线+六NPC，确认情绪、授权与响度后扩展其他语言；浏览器设备声音不能作为统一的成品配音包。
- 每次购买前确认实际价格、计费单位、作品使用权与剩余预算；本包未附任何账户密钥。

### C · 委托美术或动画师

采用示例工时单价 **150–350元/小时** 作内部预算假设（不是市场报价）：

| 项目 | 估计工时 | 假设金额 |
|---|---:|---:|
| 8个角色/动物的重点精修、材质、基础绑定 | 40–80小时 | 6,000–28,000元 |
| 6段短片的镜头、动画、灯光与输出 | 24–48小时 | 3,600–16,800元 |
| 导入、性能、碰撞、动作检查 | 12–24小时 | 1,800–8,400元 |
| 合计 | 76–152小时 | 11,400–53,200元 |

另预留10%–15%返工缓冲；真人配音、母语校对、音乐授权、渲染农场、税费和云托管不在此表中。正式委托必须按资产数量、动作数量和修改轮次重新报价。

**建议决策：**先选A保持作品展示；如果值得继续，选B做一章验证。只有明确需要商业级资产时再询价C，不建议为了单次作品集展示直接投入全套委托。

## 制作接口

- `web/sculpted-models.js`：当前模型可编辑来源；`web/assets/models/*.gltf`：导出的几何与层级。
- glTF 当前采用节点关节变换，不是完整的蒙皮骨骼动画文件；下游美术师需要进一步绑定和烘焙动画。
- `web/cinematic-content.js`：五语言台词；`web/assets/cinematics/manifest.js`：影片和音频映射。null 表示未制作，禁止伪装完成。
- 每章 voice 对象以语言作为键，内部为 male / female / matureMale / matureFemale 和该章生物种类；音频路径必须为项目内可访问的文件。
- `web/transitions.js`：输入锁定、切章队列、影片回退、黑幕与字幕生命周期。
- 替换影片后需重新测加载失败、慢网、跳过、暂停、后台切换与浏览器自动播放限制。3秒只约束加载卡，不保证任意网络在3秒内传完大视频。
- 新模型最大尺寸改变后，必须同步碰撞半径和摄影距离，不要只替换外观。
