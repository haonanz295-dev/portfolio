# 对话深渊 公开版产品需求

范围：PC单人探索Demo；此公开版不包含私人论文、研究原文或作品集资料。

## 产品定位与价值目标

为希望缓解社交紧张、减少被评价压力的成年玩家，提供一款单人、可自主探索的海洋陪伴游戏。玩家通过身体动作、共玩、可选文本表达及自主回顾，与海洋伙伴建立低压力的相遇。

| 用户要完成的事 | 产品承接 | 验证方式 |
|---|---|---|
| 想休息，又不想被迫聊天 | 自由探索、安静独处与可关闭邀请 | 能否在不完成对话的情况下继续游玩 |
| 想尝试接近，但不知道如何开始 | NPC温和邀请、动作与四种共玩入口 | 是否知道可以接受、拒绝或中止 |
| 想表达复杂感受，但担心说错 | 自由输入、意象起点、回应确认与修正 | 是否理解系统回应可以不认同 |
| 想保留体验，又担心隐私 | 本机手记、纯净照片、独立的数据分享开关 | 是否分得清保存到本机与上传 |

### 产品目标

首先建立“可进入、可探索、可拒绝、可回顾”的稳定体验闭环，再验证陪伴与表达是否舒适。当前不以在线时长、互动数量或付费转化作为最高目标。

### 产品边界

当前为18岁及以上的单人作品级Demo，不是诊疗或紧急支持服务。无联机、排行榜、强制聊天或以问答解锁装备的机制。暂不设计商业化与充值系统。

产品假设 H1：可拒绝的伙伴邀请有助于玩家愿意继续探索；H2：动作与共玩能提供文本以外的接近入口。以上需新增用户研究验证，不写为已证实效果。

## 目标用户、任务与痛点

| 情境画像（假设） | 当前困扰 | 期望结果 | 设计响应 |
|---|---|---|---|
| 谨慎进入者 | 怕被测试、被命名或被迫披露 | 先看看，保持自主性 | 游客、可跳问答、无病史字段 |
| 希望被温和陪伴者 | 不敢先发起，也不愿被打扰 | 有人可接近，但能说不 | NPC邀请、安静模式与冷却 |
| 喜欢主动探索者 | 重复对话和机械任务降低兴趣 | 通过发现建立连接 | 键鼠游动、小游戏与摄影 |
| 感官偏好较轻者 | 镜头惯性、声音或光点较多 | 平稳可控的体验 | 轻柔设置、三路音量与暂停 |

### 目标人群

首发面向18+、愿意进行独立体验的成年玩家，重点覆盖年轻成年人的探索、陪伴与表达需求。18–24、25–30、31+为当前年龄段选项；不以诊断、外向程度、MBTI或星座决定能否游玩。

### 运营与研究用户

发布者需要查看自愿分享的统计、接收反馈、维护素材与内容草稿；研究人员需要清楚区分产品事件、玩家自述与研究测量。当前仅有一个发布者权限角色，没有研究员多级账号。

### 招募假设与排除边界

建议先邀请具有不同探索习惯的成年志愿者做小规模可用性验证，不用疾病标签招募或在界面区分“患者/普通人”。未成年人暂不进入当前体验；正式研究招募与同意流程另行制定。

### 必须统一的调度规则

全局暂停和退出优先于任何活动。对话、活动、摄影同一时刻只保留一个主要交互上下文；打开新活动前先调用旧活动清理。关闭浮层后恢复进入前可恢复状态，不能重复启动计时器。

### 操作中止与异常

主动移动中止带路或姿势；换海域清理邀请、活动对象与摄影配置。带路遇到阻挡超过约3秒，应停止并提示自行绕行。后台不可用不影响本机探索。

验收重点：Esc、移动键、切海域、重复点击、窗口失焦和页面关闭时，活动状态不残留、不重复结算。

用户故事：作为初次体验者，我希望先明确可以如何进入、哪些信息必填，避免为游玩披露真实身份或病史。

| 字段 / 行为 | 规则 | 保存与上传 |
|---|---|---|
| 称呼 | 可空；默认“旅人”；最多16字 | 本机；不上传 |
| 年龄段 | 18–24 / 25–30 / 31+；必须选择 | 同意分享后可上传 |
| 日常状态 / 本次意愿 | 可跳过；意愿含独处、陪伴、表达、探索 | 同意分享后可上传 |

### 验收 AC01

Given 未完成年龄确认，When 点击游客或开始，Then 明确提示选择年龄段；选择未满18岁时返回入口，不进入体验。其余个人字段可跳过，不影响海域、装备与玩法。

### 待收敛的本机保存规则

当前档案、手记、外观使用不同存储路径。游客身份临时，并不自动意味着所有派生数据都不落盘。P0：统一保存说明和“清除此设备数据”操作，分别列出档案、手记、外观及本次服务器记录。

正式对外前补齐产品发布者和联系方式。不得把本机档案称为密码登录，也不承诺换电脑后自动恢复。

## 内部计算、样例与参数边界

### 评分公式

维度值为对应两题分值的平均。未作答按3处理；当前“跳过问答”清空整组答案。策略档位 tier = clamp(6 − round((自主探索 + 靠近节奏) / 2), 1, 5)。本式仅决定邀请策略，不用于心理状态推断。

| 策略档 | 基础邀请间隔 | 展示口径 |
|---|---|---|
| 1 | 150秒 | 内部策略编号，不显示人格标签 |
| 2 | 128秒 | 玩家可主动发起，NPC也可温和邀请 |
| 3 | 106秒 | 中性默认；全部跳题时使用 |
| 4 | 84秒 | 适当缩短等待，仍要求明确接受 |
| 5 | 62秒 | 不能覆盖低陪伴意愿或独处选择 |

### 修正项

邀请间隔 = [基础间隔 +（陪伴意愿 < 3 时加60秒）] × 安静时间系数。Q4选择更长安静时间时系数为2，否则为1；拒绝或忽略后再延长至双倍冷却。新奇偏好≥4优先考虑追光，否则先观景；感官轻柔≥4推荐低音量、低粒子和低惯性。

| 例子 | 结果与检查 |
|---|---|
| 全部跳过 | 五维均3，tier=3，基础间隔106秒；仍能关闭邀请 |
| 自主1、靠近1、陪伴1、安静系数2 | tier=5，修正间隔(62+60)×2=244秒；不因探索被动而密集打扰 |
| 自主5、靠近5、陪伴5 | tier=1，基础150秒；任何时候仍可主动找NPC共玩 |

服务端按五维数值重新计算档位，不信任客户端上传的tier。当前spaceMultiplier仅保留在本机运行配置；服务端记录不能完整重放邀请策略，需P1补充配置版本与有效参数。

## 可接受、可拒绝的NPC陪伴

用户故事：当我希望有人带一段路时，伙伴可以靠近并提出邀请；当我只想独处时，系统应留出空间，不把拒绝解释为失败。

| 触发 / 状态 | 产品规则 | 验收 |
|---|---|---|
| 发起条件 | 自由探索、无摄影/活动/模态、邀请开启且间隔到达 | 活动中不叠加邀请，暂停时不倒计时 |
| 邀请出现 | 文案说明具体活动，提供“一起去/这次先不用/今天安静探索” | 三个结果均有清楚反馈 |
| 接受 | 先清理旧活动，再带路或开启对应共玩 | 点击后只生成一个活动实例 |
| 拒绝或18秒无响应 | 收起提示，回自由探索，延长冷却 | 不扣奖励、不变暗、不自动带路 |
| 安静探索 / 关闭邀请 | 停止主动邀请，保留主动寻找NPC入口 | 切海域不擅自重新开启 |
| 接受带路后 | 伙伴前行，角色慢游；到达观景点进入摄影 | 移动键即时中止；阻挡时安全停下 |

### 首个邀请与后续间隔

当前初始变量存在45秒值，正式进入流程会按偏好重新赋值。P0以“完成进入并开始自由探索时统一设置nextInvite”为唯一规则，避免重入或访客路径产生不同首邀行为。

### 自然感约束

邀请不占满视野，不伪装系统告警；伙伴靠近保留舒适距离，鲸类更远。即使停留较久，也不能强制把玩家拉入对话或共玩。

不得以拒绝次数自动判定社交焦虑程度。所有策略只描述体验配置与本次交互行为。

### 统一角色能力声明

角色配置应显式声明canGuide、canPlay、preferredDistance、moveSpeed、animationSet等能力。菜单只展示当前伙伴支持的动作；暂不可用说明原因，不允许海星被错误选为游泳带路对象。

### IP与实时资产

角色三视图、动作概念及线稿是美术目标；现有八份glTF为简化几何、材质和节点层级，不含完整蒙皮或烘焙动画。角色人设不与用户的诊断或“缺陷”一一绑定。

鱼类不应持续吐人类式呼气泡。当前声呐光环是童话反馈符号，应与真实气泡和生物发声区分。

|---|---|---|

### P1美术与动画升级

替换精修模型时保持根节点、前向、尺寸和动作事件约定，重新校验所有碰撞体。动作质量优先保证剪影、重心与连续性，再增加细节；不能因更精美的外观移除物理边界。

所有数值为当前实现参数，不是医学、生物力学或真实潜水训练标准。呼吸声为氛围，可关闭，不要求玩家配合呼吸。

## 四种小游戏与温和结果反馈

| 玩法 | 开始 / 核心行为 | 完成条件 | 失败、中止与再玩 |

### 活动公共协议

开始前说明目标与退出方式；结束或退出清理目标物、伙伴行为和监听器；再次开始重置本局状态，保留本趟足迹统计。选择新姿势、切海域或打开其他主要活动时先结束当前活动。

### 鼓励文案

完成：“这段同行已经很珍贵。” 未完成：“可以再试一次，也可以继续随意探索。” 不使用失败羞辱、比较分数或把赢得游戏与心理改善绑定。

活动成绩不解锁表达权、装备、数据分享或其他海域。不要把完成率单独用作玩家健康或能力指标。

## 表达、确认、修正与自主回顾

当前表达系统为本机作者脚本和关键词分支，没有调用大模型。必须保留可见说明，允许玩家不认同回应。文本输入上限400字，自选手记600字。

| 步骤 | 产品行为 | 验收 |
|---|---|---|
| 表达起点 | 自由输入、“一阵雾/一点微光”等意象与可编辑句子起点 | 不填写也能离开；起点不自动发送 |
| 送出回声 | 有限脚本回应，不判断用户心理状态 | 空输入温和提示，不生成虚假理解 |
| 确认与修正 | 贴近 / 我想修正 / 不舒服 / 先跳过 | 修正回输入框；停止交还探索控制 |
| 自选回顾 | 可以记录预期与实际发生，也可留空 | 保存与退出不依赖“积极”内容 |
| 本机手记 | 查看、导出、逐条删除和清空 | 清空有确认；删除后不再出现在列表 |

### P0一致性修复 F09

experience.js与reflection.js各自挂载了确认按钮，存在重复表达确认入口。合并为单一回应确认组件，由一个状态机管理显隐；同一次发送只能触发一次确认流程和一次手记引导。

### 数据约束

原文、手记与逐题答案不进入当前统计接口。玩家主动选择“保存到手记”才保留内容，导出应提示可能包含私人表达；不因选择“不舒服”而要求解释。

仅靠关键词的紧急提示不能视作可靠风险识别。AI模块上线前需单独建立评估与回退机制，按相关功能要求。

## 可控的AI回应，不替代游戏与判断

### 目标与接入范围（P2规划）

AI只承接玩家明确发送的可选文本，用于角色语气一致的回应与可选反思问题。五维策略、内容解锁、相机和角色控制仍由确定性规则负责。未同意云端处理时继续本机脚本，不影响游玩。

| 环节 | 要求 |
|---|---|
| 服务端输入 | session_ref（可空）、npc_id、scene_id、current_text、用户选择的极少上下文、response_policy_version；禁止发送完整档案或手记库 |
| 模型输出 | 结构化reply、optional_question、safety_action；系统检查类型、长度与允许枚举，不执行输出中的指令或代码 |
| 输出边界 | 回应建议≤160字、反思问题最多1个；不作诊断、疗效承诺、羞辱、依赖承诺或强迫披露 |
| 失败回退 | 超时/限流/输出不合格 → 本机温和脚本；说明未接通，不捏造模型已理解 |
| 记忆策略 | 默认仅本轮短上下文，关闭会话后不保留云端对话记忆；长期记忆必须另行评审 |
| 可观测性 | 记录模型/提示词版本、延迟、令牌量、拦截类型与回退原因；默认不记原始敏感文本 |

### 上线前评估与关闭开关

建立不少于100条覆盖表达、误解、修正、拒绝、风险和提示注入的固定测试集（建议门槛，非现有结果）。预定关键用例须全部通过，严重违规输出为0后才允许灰度；出现严重越界立即关闭云端回复、回退脚本并人工复核。

建议SLO：请求8秒超时，超过2秒显示可取消状态；限流不阻断探索。阈值与供应商、预算、数据处理条款需确认后再定，当前没有模型费用或疗效基线。

### 禁止默认上传

称呼、性别/称谓、逐题答案、对话、手记和照片不进入当前体验统计API。可选MBTI仅自述，不进入评分。统计采用随机会话ID；带有自由文字的反馈仍可能包含个人信息，不能称为绝对匿名。

### 保留与删除

当前未实现自动到期清理。正式上线前由产品与数据负责人确定保留期限、删除响应时限和备份清理策略。建议研究试运行采用最短必要期限，具体天数列为待决策，不能宣称已自动执行。

停止分享不等于删除。体验删除不联动独立反馈。当前删除凭据仅在页面内存，刷新后可能失去旧记录的自助删除能力；P0需提供删除回执/可选本机留存与发布者协助路径。

| 主指标：自主体验闭环率 | 自愿分享会话中：完成首次有效探索，且主动回顾/拍照/自主收尾之一的比例 | 当前缺少完整事件；先补埋点再建基线 |
| 首个有效操作时间 | 自由探索可控至首次移动/问候/观察行为的中位时长 | 未建立；用于发现入门阻碍 |
| 邀请可拒绝性 | 任务测试中成功拒绝并继续探索的人数/参与人数 | 建议关键任务成功率≥90%；非现有结果 |
| 感官舒适反馈 | 自愿评价1–5分分布与文字主题 | 不用于医学结论；关注低分原因 |
| 控制权护栏 | 非自愿带路、退出无效、数据误上传的缺陷数 | 发布前关键缺陷为0 |
| 稳定性护栏 | 崩溃、状态残留、保存失败与低帧率情况 | 按相关功能要求测量，不能用活动多证明健康 |

### 当前可用事件

invite_shown/accept/decline/quiet；guide_start/arrive/stop；race、hide、resonance、garden的start/complete/try/stop；photo_open/save、region_visit、journey_end/restart及动作计数。当前为累计聚合计数，无逐事件时间线。

### P1补充与口径

补充exploration_ready、first_control、invite_ignore、response_confirm/revise/stop、reflection_save及consent_version。新增前评审必要性，保持不上传文本。pause和后台挂起时间不计有效探索秒数；15秒同步会遗漏最后一小段，不能当精确训练时长。

只有同意上传的样本会进入指标，存在选择偏差。无公共用户基线，任何目标都是建议的产品验收阈值，不是已经达到的结果。

## 测试流程与问卷样张

### 下一轮可用性测试（建议方案）

邀请8–12名不同探索偏好的成年志愿者，进行约20分钟自由体验与访谈；不按临床诊断分层。先说明可退出、可不分享数据。记录操作问题和自述感受，不把此样本作为疗效检验。

| 任务 | 观察点 |
|---|---|
| 游客进入并跳过问答 | 是否知道必填项、是否感到被贴标签 |
| 与伙伴相遇并拒绝一次邀请 | 是否能找到拒绝入口、拒绝后是否安心继续 |
| 接受带路后中止 | 是否理解移动能立即取回控制 |
| 任选小游戏与摄影 | 目标与反馈是否清楚、照片是否纯净 |
| 表达一次并选择修正/跳过 | 是否把脚本理解为判断；重复按钮是否消失 |
| 查看分享、导出并清理本机数据 | 能否区分本机保存、服务器同步与删除 |

### 体验后短问卷（自编可用性题，不是心理量表）

1–5分，另提供“不想回答”：①我知道下一步可以做什么；②我可以按自己的节奏探索；③我可以轻松拒绝或结束邀请；④声音、镜头和画面让我舒适；⑤我愿意再次尝试其中一项活动。

开放题：哪个瞬间让你愿意停留？哪处让你困惑或不舒服？你希望伙伴何时靠近？你认为哪些信息留在本机、哪些会发送？你最想保留或删去哪个功能？

问题和顺序避免暗示“是否被治愈”。疗效研究如需量表、对照或长期追踪，应由具备相应能力的研究团队另立方案。

## 性能、可用性与离线降级

| 类别 | 建议验收目标（待测） | 异常与降级 |
|---|---|---|
| PC性能 | 约定参考机型后，连续10分钟探索中位帧率≥45fps、P95帧耗时≤33ms | 降低粒子、阴影与分辨率；不降低退出能力 |
| 资源加载 | 本机冷启动资源准备≤10秒；公网指标在网络条件确定后再定 | 显示加载状态、错误原因和重试入口 |

### 验收环境登记

每次记录OS、浏览器版本、CPU/GPU、内存、屏幕、画质、网络、包版本与资源哈希。未指定最低配置前，不能对所有PC或设备作帧率保证。当前移动端设计比例不等于移动性能通过。

移动端触控、横竖屏切换、浏览器手势冲突、音频自动播放和文件下载均是P1专项验证项。

## 默认克制的数据和回应边界

| 场景 | 必须行为 | 上线前检查 |
|---|---|---|
| 一般紧张或表达 | 保留角色温和回应，允许修正、不认同和停止 | 不诊断，不用人格档位评价用户 |
| 明确危险表达 | 停止角色扮演式回应，提示联系当地紧急服务或身边可信任者；提供暂停/退出 | 不继续游戏奖励式对话，不承诺实时救援 |
| AI云端处理 | 单独解释数据接收方与用途，未同意继续脚本 | API密钥只在服务器，输出经校验 |
| 研究数据分享 | 默认关闭，与反馈/云端AI同意分开 | 取消分享不偷偷恢复；删除路径真实可用 |
| 发布者权限 | 密码哈希与令牌；所有读取、导出、文件和修改鉴权 | 未登录不可访问数据；删除需确认 |
| 上传文件 | PNG/JPEG/GLB2.0/内嵌glTF2.0，签名与大小校验 | 拒绝外部资源引用，不执行上传内容 |

### 当前安全实现与局限

后台使用PBKDF2-SHA256（310000轮），随机发布者令牌8小时有效；重启或退出失效。当前关键词风险提示覆盖有限，不能承诺识别所有危险表达；公网进程管理、HTTPS、监控、生产限流与审计仍需部署工作。

### 关照原则

不要求疾病证明，不分“患者专属”登录，不用“正常/异常”标签。建议入口说明适用范围、暂停与求助边界；任何不适都可以停止，收尾不要求积极评价。

本页是产品功能与发布要求，不替代具体地区的合规评估、研究审批或专业医疗服务。
