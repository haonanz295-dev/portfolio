# 海洋界面动效 · Demo v0.6.1

2026-11-12。该补丁基于v0.6，使用本地SVG、CSS和原生界面事件，不需要视频生成额度。

## 使用效果

- 专属光标：海流箭头、邀请圆环、按下圆点三种状态；海域移动时有轻微上浮气泡，文本区域保留文字光标，禁用控件保留不可用提示。
- 图标：罗盘摆动、相机对焦、声呐扩散、手记翻页、装备浮动、气泡上升、音符轻摆、菜单线条错动、挥手、同行、休息、旋转、心律、对话、返回、开始、保存、档案、贝壳、海花和月亮，共21种可复用SVG。
- 状态：鼠标悬停和键盘聚焦触发图标专属动作，点击触发短促确认；长时间停留不会无限反复播放图标动画。
- 界面：菜单/装备/对话等弹窗浮入，离开时有150ms装饰性淡出；邀请、活动、附近互动和摄影面板出现时也有浮入效果。实际关闭、焦点与游玩逻辑即时执行，动画不锁住操作。
- 摄影：保存时增加低强度的短暂快门亮度反馈，不是全屏强白闪。
- 动态生成的问卷、按钮和后续重新生成的界面会自动补齐对应图标。

## 动效参数

| 层级 | 时长 | 用途 |
|---|---:|---|
| 按钮状态 | 160–180ms | 颜色、边框、轻微位移 |
| 面板入场 | 280ms | 12px上浮、轻缩放到原位、透明度 |
| 面板离开 | 150ms | 惰性快照淡出；不保留焦点或可点击区域 |
| 点击确认 | 380ms | 图标短促缩放回弹 |
| 图标专属动作 | 550–800ms | 单次轮廓运动 |
| 光标气泡 | 600ms | 最多8个，产生间隔至少85ms |
| 摄影反馈 | 220ms | 最高12%浅色叠加 |

统一曲线：`cubic-bezier(.2,.75,.25,1)`。没有屏幕震动、强烈闪烁或物理振动模拟。

## 可访问性与兼容

- 系统“减少动态效果”、新版设置“减少动态效果”、原游戏“减少粒子与镜头惯性”均可关闭新增动态效果。关闭后恢复系统光标、取消尾迹、图标动作、面板浮动和摄影亮度反馈；功能仍可使用。
- 触屏使用系统行为，不显示自定义鼠标，也不依赖悬停；按钮保持至少44px高度。
- 输入框使用文字光标，图标对读屏隐藏，不重复按钮名称；键盘焦点保留明显边框。
- SVG光标由支持该格式的浏览器显示，不支持时自动回退系统光标。
- 本次验证使用Windows Edge的桌面/触屏模拟与系统减少动效模拟；没有声称完成Mac Safari真机测试。

## 文件与复用

- `dialogue-abyss/web/ui-motion.js`：按钮图标映射、动态界面接入、装饰性关闭快照、光标尾迹、减少动效策略。
- `dialogue-abyss/web/ui-motion.css`：动效规则、21类图标动作、光标状态。
- `dialogue-abyss/web/assets/ui/motion/*.svg`：独立矢量图标源文件。
- `dialogue-abyss/web/assets/ui/cursor-*.svg`：三个32×32光标；箭头热点为(8,6)，圆环与按下为(16,16)。
- 所有素材为本项目原创SVG与代码，不含商业游戏的图标或字体资源。

旧主页和章节转场保留各自的动画流程。新的通用面板动画主动排除章节全屏转场，避免两套过渡相互干扰。
