# 对话深渊 Demo v0.6

2026-11-12 · PC浏览器作品展示版

## 本次更新
- 七种海洋伙伴改为连续曲面、弯曲触须与更细的材质细节，潜水员增加面罩框、软管、装备扣件。
- 独立模型工作室：旋转/缩放、图片导出、glTF下载；八份模型已重新导出。
- 整合v0.5的动态首页、语言/声线选择、六章字幕序言、加载、淡入淡出、跳过和暂停阅读。
- 模拟心律随深度和游动变化；靠近伙伴和安静观察可帮助平稳，声音默认关闭。
- 猜拳与海晶寻找，以及安静观察替代准备。正常章节出口增加准备条件；菜单保持自由换章。
- 保留原四小游戏、摄影、个性化邀请、可选表达、本地档案与独立同意的数据分享。

## 运行
Windows双击 Launch.cmd（需要Python 3.10+）；或直接打开“开始游玩.html”进行本地单机体验。Mac/Linux进入web目录执行 `python3 backend/server.py --port 4196`。

游戏默认： http://127.0.0.1:4196/ 。后台默认： http://127.0.0.1:4196/admin 。启动器遇到旧版占用端口时会选择空闲端口并自动打开实际地址，以窗口显示的地址为准。这些地址只在启动服务的电脑上有效。后台首次设置自己的密码。静态托管无法运行Python后台，不能把GitHub仓库地址当成线上后台。

## 已知边界
- 美术为经改进的程序化Demo模型，不是外包级精修雕刻与蒙皮资产；Godot仍是迁移基础。
- 六段精修影片、正式多语配音未制作；当前为字幕序言与可选设备语音预览。
- 新设置和章节支持五语言；旧问卷、部分活动与后台仍有中文文案。
- 心律为虚构状态，稳定时间累计且允许缓慢回退；不采集真实心率，不作临床判断。
- 研究有效性、正式上线、安全与性能仍需后续验证。详见 FUTURE-DEVELOPMENT.md。
